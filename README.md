# Common Sense Education Community Review Archive

Systematic preservation of Common Sense Education community reviews for widely-used K-12 EdTech products. These reviews from teachers, parents, and students represent over a decade of firsthand accounts that are no longer publicly accessible.

**Maintained by:** Meredith Bouvier, PhD | NET Lab, Inc.  
**Dataset:** [Open Science Framework (OSF)](https://osf.io/ehbfv/)  
**Status:** Archive complete — collection closed March 2026

---

## What Happened

Community reviews were publicly accessible on Common Sense Education product pages as recently as early 2025, confirmed via the Internet Archive Wayback Machine. By January 2026, the dedicated review sections had been removed. By March 2026, individual review URLs were also inaccessible.

This repository preserves what was collected between February 3–16, 2026 before the archive closed entirely.

## Analysis Pipeline

The analysis pipeline is a three-step process. Download the CSVs from OSF into a `data/` directory before running.

### Step 1 — Score reviews
```bash
python 01_score_reviews.py
```
Applies a 77-term concern vocabulary index across seven thematic categories. Outputs all 619 scored reviews and a critical subset (score ≥ 2). No API key required.

### Step 2 — Thematic analysis
```bash
python 02_analyze_themes.py
```
Sends critical reviews to the Claude API for structured thematic analysis, one call per platform. Requires `ANTHROPIC_API_KEY`. Estimated cost: $1–2 total.
```bash
export ANTHROPIC_API_KEY=your_key_here
python 02_analyze_themes.py --platform iReady  # test one platform first
python 02_analyze_themes.py                     # full run
```

### Step 3 — Summary report
```bash
python 03_summary_report.py
```
Reads per-platform JSON outputs and generates a cross-platform markdown report.

### Supplementary — Word cloud
```bash
python generate_wordcloud.py
```
Generates a 300 DPI word cloud from the full 619-review corpus.

## How the Data Was Collected

For full methodology documentation including data cleaning steps and known limitations, see METHODOLOGY.md.

**Stage 1 — URL collection (manual):**
- Google search: `site:commonsense.org/node "community review of [product]"`
- JavaScript console script (`console_script.js`) extracted review URLs
- Collection bounded by Google search index — not a complete census of all reviews ever posted

**Stage 2 — Scraping (automated):**
- Python script fetched each URL with a 2-second rate limit
- Structured fields extracted and exported to CSV
